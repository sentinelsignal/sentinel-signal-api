# Security Policy

## Reporting a vulnerability

Email **security@sentinelsignal.io** with a description, the affected endpoint or file, and steps to reproduce. Please do not open a public issue for security reports.

We acknowledge reports within 3 business days and keep you updated until the issue is resolved. We will credit you in the fix notes unless you ask us not to.

## Scope

- The Sentinel Signal API at `https://api.sentinelsignal.io`
- The assets in this repository: the OpenAPI contract, SDK wrappers, mock server and examples

This repository never contains live credentials. If you find something that looks like a real key or secret here, please report it as above.

See also <https://sentinelsignal.io/.well-known/security.txt>.
